# The Retro Shelf on a Steam Deck

The Linux version runs on a Steam Deck, and TV mode makes it work with the Deck's controls.

## Install it (Desktop Mode, once)

1. Hold the power button and choose **Switch to Desktop**.
2. Open Firefox, go to the [Releases](https://github.com/colingalbraith/the-retro-shelf/releases) page and download
   the file ending in `linux-x86_64.AppImage`. Put it somewhere it can stay, like your home folder.
3. Right-click the file → **Properties** → **Permissions** → tick **Is executable**.
4. Open it once and turn on **Settings → App → TV mode**. Add your games: drag them onto the window, or use
   **Settings → Library → Watch a folder** for a folder of games on the SD card.
5. In Steam (still in Desktop Mode): **Games → Add a Non-Steam Game to My Library…**, click **Browse…**, choose the
   AppImage and click **Add Selected Programs**.

## Play (Game Mode)

1. Switch back to Game Mode. The Retro Shelf is in your library under **Non-Steam**.
2. Before the first start, open its page → controller icon → choose the **Gamepad** layout, so the buttons act like a
   controller rather than a mouse.
3. Start it. The D-pad browses, A plays, B goes back, Select opens a game's options, Start opens Settings. Hold Start
   in a game to come back to the shelf.

It updates itself, like on other computers.
